# Supporting TurtleBot 4 simulation and Nav2 package

Subset of the earlier saved-map project used by Bài 7. Includes official
TurtleBot4 world/spawn launch integration, AMCL/Nav2 parameters, map, RViz and
host renderer helpers. It contains no new experiment results. See the root
README and src/turtlebot4_voice_nav for the Bài 7 implementation and evidence.
